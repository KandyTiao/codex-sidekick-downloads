# Codex Sidekick｜Codex 搭子 · 详细使用说明

[English overview](../README.md) · [简体中文介绍](../README.zh-CN.md)

以下命令在解压后的程序包根目录或已安装目录中执行。仅完成 Windows 实测；macOS 兼容性尚未确认。

## 监控栏与配色

新建聊天可能暂时使用 Codex 的客户端编号。v0.4.2 从 Codex 保存的对应关系读取正式编号，侧栏与监控栏使用同一份数据；不通过标题猜测，也不会把远程或 ChatGPT 会话混入本地统计。正式编号或首次本地记录尚未写入时显示“等待任务记录”和 `—`，随后自动更新。当前聊天超出最近 80 条或已经归档时按编号补读，日常轮询仍保持原来的范围。收起侧栏时保留可识别聊天的监控，切换任务不会沿用上一个聊天的累计值。

- 固定到标题栏下方后锁定位置；先点击锁形按钮解锁，才能拖动横框空白、推荐行或状态文字。再次点击可回到标题栏下方并锁定。已移除重复的六点手柄，两行文字直接共用左侧基准。右下角的小折角可拉宽、拉窄，窄窗口会自动限制宽度。
- 点 `−` 收起成简条，点 `+` 展开；点 `×` 隐藏后，用头像上方的 `◈` 恢复。键盘聚焦监控栏后可用方向键微调位置。
- 鼠标悬停“响应均速”自动显示调用明细与测速说明，移到说明面板可继续阅读，移开后自动收起；点击仍可展开明细。
- 推荐模式右侧明确显示“推荐理由”与信息图标，悬停文字或图标均可阅读推荐说明，窄窗口保持文字与图标为一组。
- 项目右键／选项菜单和聊天名称前的小色标提供 5 列 × 4 行的 20 个选项：GPT 主题色、18 种固定色、赛博幻彩。默认“活力绿”保持 `#21E08C`；色名参考简短、自然、有光感和画面感的命名方式，由用户确认。色板和悬停只显示色名与色值。旧颜色 ID 继续兼容。保留 Codex 原生聊天右键菜单；支持 DOM 菜单的客户端也会在聊天选项中显示色板。
- 项目颜色应用到文件夹图标与名称；聊天小色标、累计 Token 方块和名称三者同步继承项目颜色，也可为聊天独立设色。色板中点“跟随项目”取消独立颜色。Token 方块继续显示原累计用量悬停提示；原生未读、运行图标保持其含义。
- 文件夹和聊天的菜单色板采用紧凑布局：14px 色块、较小字号与间距，保持 5 × 4 的 20 个选项；Token 环与监控栏的主题面板保持原尺寸。
- 右键 Token 环，在菜单选择“主题选色”；也可点击监控栏的 `◐`，选择一次，两处同步变化。原生界面中，Token 环左键打开或隐藏算力分析面板，再点恢复同一标签，保留所选时间范围；隐藏不会关闭页面。如果其他文档标签正显示，点击会切到算力分析。当前聊天保持不变，本地网页版仍用链接打开分析。默认保持活力绿；第一格“GPT 主题色”跟随 Codex 的明暗主题，第二格“活力绿”是第一个固定配色，最后一格“赛博幻彩”使用电光青、荧光紫和玫红渐变与柔和光晕。Token 环表示账号每周剩余额度，百分比不是精确 Token 余额。

## 算力账单与分享

Token 环右键菜单提供“算力分析”和“导出报告”；账单页面位于本机 `/analysis`。支持最近 5 小时、今日、本周、本月、近半年、今年与自定义日期，按小时、每日或每月汇总。展示 Token、活跃天数、模型与聊天分布、调用明细和有真实依据的使用成就。

历史索引在后台增量读取所有可读聊天文件，包含归档聊天，不额外调用模型。统计只包含带时间的 `token_usage_record`；旧记录只有累计值时不倒推日期。历史覆盖范围会显示在页面和报告中。账单基于当前 Codex 数据目录，无法确认跨设备或历史账号归属；不宣称全账号完整账单。缓存含于输入、思考含于输出，不重复加总；Token 不等于精确费用或套餐扣减。

导出面板先预览分享卡片，再保存 PNG（朋友圈或 Instagram 尺寸），或保存可双击打开的 HTML 报告。卡片在本机 Canvas 绘制，不额外调用模型，不包含聊天名称或账号信息；完整 HTML 包含本机聊天明细。报告保存在安装目录 `data/reports/`；可在私有 `config.json` 中设置 `reportArchiveDir`，同时复制到指定归档目录。索引缓存保存在 `data/usage-ledger.json`，不含聊天正文或登录凭据。报告与缓存均排除在发布包之外。

## 动态模型建议

每 2 秒读取本机新消息。延续任务中的多类工作与多项约束会累计影响复杂度；简短确认沿用前面的任务，明确局部修改可回到轻量建议。轻量标记为浅绿，复杂标记为暖琥珀色；模型、思考或速度建议变化时显示短暂提示。Ultra 只在深层任务且当前模型支持该档位时建议。所有识别均为本地规则，可能误判，不额外调用模型，也不自动切换用户当前选择。
- 监测网页用项目旁的圆点和聊天旁的 `◌` 打开同一套色板。颜色与布局保存在安装目录 `data/settings.json`，原生与网页共用设置，逐项合并保存。

## Windows 安装

Windows 默认开启自动加载：登录当前 Windows 用户后约 8 秒，托盘守护启动监测并打开带增强接入参数的 Codex。守护完整检查确认 Codex 主进程全部退出后就自动接管，不再额外等待原先的 8 秒重启宽限；实际打开耗时取决于系统。守护在后台运行，不弹出命令窗口。重复打开入口会复用本安装的守护和监测服务。

v0.4.5 修复从 Codex 内启动搭子后，后台可能在 Codex 完全退出时一起消失的问题。现在由现有 Windows 桌面独立启动守护，再由守护启动监测；入口会等待守护初始化，失败时明确报错，不静默保留一个会随 Codex 退出的后台。

v0.4.6 进一步缩短退出捕捉的间隔：每 500 毫秒轻量检查已识别进程的退出状态，发现退出就立即完整复查；常规后台维护仍每 5 秒进行。等任务结束后正常完全退出 Codex，交给搭子自动打开；需要手动打开时，使用桌面 **Codex 搭子** 入口，让启动参数一并加载。

安装后也会在当前用户桌面创建 **Codex 搭子** 快捷方式，方便手动打开。入口每次重新发现 Codex 的已注册安装路径，避免更新后的版本目录变化使旧路径失效。已有用户可双击 `创建桌面快捷方式.cmd` 单独修复桌面入口。`-NoDesktopShortcut` 不创建桌面入口；`-NoShortcuts` 不创建桌面与安装目录的常规入口，登录自启动由独立的 `-NoAutoStart` 控制。

Codex 更新后通常不需要重装搭子。v0.4.7 针对更新期间 Store 注册或版本路径短暂变化，限次重新发现后再启动；接入成功需要调试连接可用且本版本监测已登记原生界面连接，打开了程序或端口可达都不会单独被判为成功。如果官方更新或其他入口抢先以普通方式打开 Codex，无法为已运行的窗口补加增强接入参数：自动守护会提示等待，不关闭正在运行的任务。

需要恢复时，等任务结束后正常完全退出，交给守护自动接管；也可双击桌面 **Codex 搭子**，在修复确认中选择“是”来**修复并重开**，或选“否”稍后处理。只有你确认修复，入口才请求 Codex 正常关闭；未退出时会提示用 Codex 菜单退出，不强制结束进程。确认窗口打开时已释放启动锁，后台恢复不会因等待确认而被锁住。若自动重开后仍无组件，可查看本地网页、`logs/launch.log` 和 `logs/watcher.log`，检查新版 Codex 的界面兼容性。

1. 下载仓库 ZIP 后解压到软件盘，先安装并登录官方 Codex。需要 Node.js 24+；支持使用 Codex 已有的 Node 运行时，或自行安装 Node 到 D 盘。
2. 双击 `安装到软件盘.cmd`，或在解压目录打开 PowerShell，执行：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
   ```

   默认装到 `D:\Software\CodexSidekick`。无 D 盘时会要求输入目录，不会自动回退 C 盘。自选目录：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1 -InstallDir "E:\我的软件\Codex增强包"
   ```

3. 安装后监测与托盘守护自动运行。如果 Codex 尚未打开，守护会启动增强连接；普通 Codex 已在运行时，等任务完成后**正常完全退出 Codex**，随后自动恢复，或从桌面搭子入口确认修复并重开。
4. 需要查看网页时，打开 `入口\查看实时监测.lnk` 或 `启动监测.cmd`。Windows Store 和普通安装版本均支持；也可用桌面入口、`入口\启动 Codex 增强版.lnk` 或 `启动 Codex 增强版.cmd` 手动打开。

首次安装默认开启自动加载；升级会保留原有的关闭选择。双击 `开启自动加载.cmd` 可注册当前用户的登录启动项并立即开启守护，`关闭自动加载.cmd` 则撤销启动项并停止守护，当前 Codex 与监测继续运行。安装参数 `-NoAutoStart` 可关闭此功能。`-NoStart` 只阻止安装当下启动进程，仍按设置注册登录启动项；只复制安装而不启用任何自动启动时，需同时使用 `-NoStart -NoAutoStart`。

托盘菜单提供“打开 Codex”“算力分析”“暂停自动恢复（本次）”“关闭登录自启动”和“退出搭子（本次）”。想暂时完全退出 Codex 时，先暂停自动恢复；退出搭子会停止守护和监测，本次不再自动重开，但下一次 Windows 登录仍按原设置启动。关闭登录自启动后，后续使用桌面入口或增强版入口手动打开。

自动加载复用官方 Codex 已有的登录状态；首次登录、登录过期或官方要求重新认证时，仍须在官方窗口完成认证。搭子不保存密码，也不绕过官方登录。默认在当前用户的 Windows 启动文件夹放一个小快捷方式；该目录拒绝写入时，自动改用当前用户注册表的登录启动项，升级会沿用已保存的注册表方式。系统启动项只登记软件盘内的脚本，程序、配置与数据仍保存在选定的软件盘，不因系统启动项位于 C 盘而迁移。不需要管理员权限，不修改 Codex 安装文件或官方快捷方式。之前安装的其他额度注入工具如果也在运行，应先用其关闭入口停用，避免双方重复显示。

## macOS 安装

安装 Node.js 24+ 后执行：

```bash
bash scripts/install-macos.sh "/Volumes/Software/CodexSidekick"
```

目录可自选，包括用户目录或可写的外置盘。启动用 `bash /实际目录/scripts/start-macos.sh`；正常退出 Codex 后用 `bash /实际目录/scripts/launch-macos.sh`。默认自动发现 `/Applications/Codex.app` 或 `/Applications/ChatGPT.app`；非标准位置可设置 `CODEX_APP`。运行时可以设置 `NODE_EXE`。本次没有新增 macOS 登录自启动或托盘守护，原启动流程保留。Mac 脚本与跨平台逻辑准备就绪，但未做 Mac 实机验收，GitHub Actions 运行结果也要实际发布后查看。

## 模型建议

任务识别采用本地中文／英文关键词规则，读取任务标题和近期用户要求。短确认（例如“可以，继续”）沿用先前类别；新的明确要求更新类别。悬停显示类别、识别依据和说明，规则可能误判。读取最近 2 MiB 会话尾部及后续追加记录，极长工具输出可能让较早要求不在读取范围内，此时使用标题作为依据。

- 轻量文字修改优先 Luna＋低；常规功能开发与排错优先 Sol＋高；疑难根因、架构或多重约束优先 Astra＋极高；写作、视觉方案优先 Sol＋中。
- 模型和思考档只从当前 App Server 的 `model/list` 结果选择。系列缺失时使用可选替代；没有可用列表时等待恢复。优先同系列的新版本，列表每 10 分钟刷新，失败后重试。
- 默认标准模式。检测到明确赶时间的要求且该模型支持高速时建议高速；检测到节省额度的要求，或有效每周剩余额度不超过 20%，优先标准。高速可能增加额度消耗，不能加快工具本身的执行。
- 高／极高属于思考强度，高速属于响应速度档。建议只提供参考，需要你手动选择；程序不发起模型生成请求，不自动切换模型或开启高速。

## 数据口径

- 累计 Token：本地 `threads.tokens_used`，与 Codex 本地统计一致。它通常是多次请求的输入加输出总量，不代表内存、费用或当前上下文长度。
- 响应均速（主栏）：`output_tokens / (完整 Token 记录时间 − 成功 HTTP 响应记录时间)`。从收到响应头起计时，排除响应前的准备与等待；输出包含思考 Token。与本机 Codex Pulse 的实际样本口径一致，用于比较模型响应阶段的速度。仅配对同一轮、前次完成之后、最终重试中的成功 `/responses` 响应；缺少此日志（例如不同传输方式或客户端更新）时显示未知。
- 调用端到端（详情）：从本次 sampling 准备到用量记录完成，包含准备、响应等待与响应阶段，不包含前一次工具执行时间。可用来判断响应前是否等待较久。详情列出最近 10 次有效响应均速的算术平均。
- 上述速度都是最近完整调用的平均值，**不是逐秒流式速度或纯正文输出速度**。每 2 秒刷新读取，生成中显示状态、呼吸圆点和累计耗时，完整调用结束后更新速度。
- 输入已经包含缓存，输出已经包含思考，因此合计仅为输入 + 输出，避免重复累加。
- 模型：当前本地调用日志／上下文的请求模型名称。不能据此确认服务端内部路由或替代模型；未知不猜测。
- 加速：仅从本次调用的 `service_tier` 映射，`default` 为标准，`priority`／`fast` 为加速，其他情况标为未知或对应模式。增强包不会自行切换模型或开启加速。
- 额度：官方 App Server 的 `account/rateLimits/read`，优先 `rateLimitsByLimitId.codex`，按真实窗口时长识别周与 5 小时，不按套餐猜测。不需要 API key，也不发起模型生成调用。
- 本地监测每 2 秒，额度每 60 秒；连接失败或数据过期时显示等待，不伪造剩余额度。后台读取最近 80 个未归档任务，原生侧栏中其他本地任务仍可按悬停读取总量。
- 项目和聊天分色：项目右键／选项菜单、聊天名称前的小色标或监测页圆点打开 5 × 4 的主题选色面板，设置存于安装目录 `data/settings.json`。

## 目录与隐私

程序、`config.json`、`data/`、`logs/`、升级前 `backups/` 都在选定的软件盘安装目录。Codex 自己的登录信息与会话仍使用原安装位置；增强包只读本地状态库和日志，**不会迁移或复制 Codex 的登录凭据**。为任务分类，会在内存中读取近期用户要求，只保留类别和规则匹配关键词；不保存或上传要求原文、对话正文、工具输出或 HTTP 请求头。

实时监测服务只绑定 `127.0.0.1:19766`，原生接入只连接 `127.0.0.1:39222`。不对局域网开放。调试接口可被同机程序访问，增强启动会启用此本地接口；需要恢复默认状态时，先关闭自动加载和监测，正常完全退出 Codex，再使用官方入口打开。

如果 D 盘是本机独立数据盘，系统重装后程序与配置可保留；仍需重新安装 Node／Codex 并登录，再运行安装脚本重新发现路径。`home`、`nodeExe`、可选 `codexBin` 可在安装目录 `config.json` 更新。不保证硬盘故障或格式化后的保留。

## 升级、关闭与恢复

Windows 启动修复：所有包信息和配置显式按 UTF-8 读取，支持快捷方式默认使用的 Windows PowerShell 5.1。启动增强版遇到错误会弹出提示并记录到安装目录 `logs/launch.log`；桌面入口支持确认后正常关闭并重开，自动守护仅等待用户正常退出，不强制结束进程。诊断模式：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/launch-windows.ps1 -DiagnosticsOnly -NoDialogs`，只检查状态，不重启 Codex。

此前已用独立数据目录的官方未登录 Windows 窗口验证 CDP 与组件脚本能接入，没有复制登录凭据。v0.4.8 已在当前官方原生窗口验证 Token 环切换分析面板、同标签恢复与范围保留，没有重开官方 GUI。本轮没有重新验收自动重开或 Windows 整机重启；其他功能仍以各自已有验证范围为准。

- 升级：用新版本安装脚本指定原目录。安装器先安全关闭自己的守护与监测，再把源码、配置和颜色设置保存到安装目录的日期备份中；原有的自动加载关闭选择继续保留。
- 暂停／关闭：托盘可暂停自动恢复，或退出搭子本次；`关闭监测.cmd` 先停止守护再停止监测，不会结束 Codex 或其他 Node 进程，也不撤销下次登录的启动项。永久关闭自动加载用 `关闭自动加载.cmd`。
- 卸载：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\uninstall-windows.ps1 -RemoveProgramFiles`。撤销本安装的登录启动项并停止守护，启动文件夹和注册表两种方式都会清理自身项目；仅清理归属已验证的程序文件，保留配置、颜色、日志、升级备份。用户需要时可自行删除整个安装文件夹。
- Mac 关闭：`bash scripts/stop-macos.sh`；正常退出 Codex 后可移除确认属于本工具的安装目录。不要移除官方 `.codex` 数据目录。

## 算力账单与分享

Token 环左键切换原生算力分析面板，隐藏后再点恢复同一标签；本地网页版仍通过链接打开分析。右键提供主题选色、算力分析和导出报告。分析按本机可读的带时间模型调用记录汇总，包含归档聊天，支持最近 5 小时、今日、本周（周一至今）、最近 7 天、本月、近半年、今年、自定义，以及小时／日／月汇总。不会从累计值推测没有记录的历史；缓存含于输入，思考含于输出，合计仅为输入 + 输出，Token 不等于精确费用或套餐额度扣减。

先选择时间范围，再点击范围下方的“确认范围并导出”。确认面板会显示起止时间、调用数和总 Token，也可直接改选范围；确认后进入预览。右键导出入口遵循同样流程。报告确认期间范围不会随自动刷新改变。

主题选色同步到 Token 环、监控栏、算力分析、HTML 报告与 PNG 分享卡片。分析页面每 2 秒读取轻量主题状态；赛博幻彩保留渐变，GPT 主题色在分析页按明暗外观使用黑白灰。不同明暗背景采用适合阅读的深浅色值。

分享卡片默认不含聊天名、邮箱、账号 ID 或个人名片。“展示个人名片”可选择公开昵称及头像，自动读取当前 Codex 能提供的头像与显示名；当前 Windows 客户端只提供头像，昵称可手动填。支持选择不超过 5 MB 的 PNG/JPG/WebP 头像和移除头像，不上传原文件，不在配置或浏览器设置里保存名片。勾选后，昵称和头像会进入确认保存的图片。HTML 完整账单包含聊天明细，适合本人留存。

HTML 报告可双击本地文件打开，也可通过浏览器打印为 PDF。报告在安装目录 data/reports/ 保存；可在私有 config.json 设置 reportArchiveDir 同时复制到指定备份目录。后台增量索引缓存在 data/usage-ledger.json，不含对话正文、半行消息或登录凭据；发布包排除全部私有数据。
